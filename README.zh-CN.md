# FilingTime：历史财务数据的时点审计

这个项目回答一个问题：**回到某个历史日期，收入数字是否已经在指定的年报集合中披露？后来的修订值有没有被填回过去？**

项目只深入研究年度合并收入及同比，涵盖预先指定的12家公司、2019—2024财年。8家公司用于开发，4家公司在规则冻结后用于评估。它连接原始财报、会计口径判断、不可覆盖的版本存储、历史查询和可复现实验。

完整第三方材料许可及分类标准的必需声明见[项目首页](README.md)和[第三方说明](docs/THIRD_PARTY_NOTICES.md)。项目MIT许可不覆盖这些原始材料。

## 快速运行

在仓库目录中使用Python 3.12及uv：

```console
uv sync --frozen
uv run filingtime verify
uv run filingtime demo
uv run python scripts/reproduce.py --work-dir ./work/reproduction
```

环境首次安装需要下载依赖。随仓库提供的查询、实验和原件重放可以离线运行；完整重解析所有财报可添加 `--reparse`。

## 可以展示的能力

- 从SEC原始文件取证，保存原文、申报编号、时间、字段位置和哈希。
- 使用Arelle解析XBRL，区分公司合并收入、分部收入和附注中的其他主体金额。
- 使用Parquet/DuckDB保存事实版本，禁止覆盖旧事实。
- 比较“财年末提前使用”“最终版本回填”“历史时点可用”三种处理方法。
- 用保留公司、对抗测试、故障注入及干净环境重放检查结果。

详见[研究报告](docs/REPORT.md)、[真实案例](docs/SOURCE_CASES.md)、[研究协议](docs/PROTOCOL.md)和[验证说明](docs/VALIDATION.md)。

## 结果边界

可用时间采用“SEC接收时间＋24小时”的固定研究约定，不代表实测市场首次获知时间。收入变化可能来自业务范围调整或会计重分类，不能直接称为错误。同比需要同一申报、同一口径的相邻年度；证据不足会明确拒判。

独立人类财务复核仍待完成。现有独立AI原文核对不冒充人工金标准，测试通过也不等于会计事实绝对真实。项目评价数据与因子构造，不声称改善投资收益。
